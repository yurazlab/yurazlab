# Размещение yurazlab.ru на VPS

Согласовано Юрием20.10.2026: весь сайт на Timeweb Cloud104.171.139.101 рядом с sellershelp.ru. Изменения SellersHelp не требуются.

Сервис yurazlab слушает только127.0.0.1:3011, nginx обслуживает yurazlab.ru и www. Отдельный пользователь yurazlab без входа; HTTPS—Certbot. Исходник: https://github.com/yurazlab/yurazlab.git, ветка main.

После git push таймер yurazlab-deploy проверяет main раз в2минуты. Новая версия собирается отдельно от работающей, проверяется на3012, затем current переключается и сервис перезапускается. При ошибке сборки текущая версия остаётся; повтор той же неудачной версии блокируется до исправленного коммита. При ошибке запуска возвращается предыдущая версия. Секреты GitHub для чтения публичного репозитория не нужны.

Лимит процесса сайта512МБ; сборки1200МБ/одноядро. Установка скриптов из ops в /usr/local/lib/yurazlab выполняется отдельно при изменении самой инфраструктуры; обычные изменения сайта таймер подхватывает автоматически. Старые релизы сохраняются для отката.

Диагностика: systemctl status yurazlab yurazlab-deploy.timer; journalctl -u yurazlab-deploy -n60. SHA размещённой версии: /opt/yurazlab/state/deployed-sha. После устранения причины неудачной сборки для повторной проверки того же SHA убрать только файл state/failed-sha.

Откат версии: остановить таймер, установить current на проверенную предыдущую папку из state/previous-release, перезапустить yurazlab, проверить HTTP и полный путь пользователя. До успешной проверки DNS не переключать. Vercel сохранён как прежнее размещение; обратный DNS: A@216.198.79.1 и CNAMEwww19b726f6dbad504d.vercel-dns-017.com. Откат DNS зависит от кэшей.
