## Размещение

Сайт размещён на Timeweb Cloud VPS рядом с sellershelp.ru. Автоматические обновления из main и откат описаны в [ops/README.md](ops/README.md).


## Структура сайта

- `/` — польза, три примера, общий кейс, подход и сотрудничество.
- `/projects` — 25 клиентских продуктов, внутренних инструментов, разработок и исторических работ с поиском, темами и явными статусами. Это не 25 готовых публичных сервисов.
- `/cases/transcription`, `/cases/reviews`, `/cases/contracts`, `/cases/ecosystem` — подробные кейсы с личным вкладом, материалами и границами.
- `/card` и `/card/contact` — электронная визитка и файл контакта.

Единый источник каталога и кейсов — `data/projects.ts`. Изображения — `public/evidence`; тестовый фрагмент договора подписан как демонстрация на вымышленных данных. Скриншоты меню показывают интерфейс, а не измеренный эффект AI.

## Локальная проверка

```sh
npm ci
npm run build -- --webpack
```

Публикация — обычная отправка проверенного коммита в `main`, затем подтверждение фактического результата на домене. Изменения инфраструктуры для обычного обновления сайта не требуются.
